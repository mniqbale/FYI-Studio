| 2026-08-07 | Architecture | **ADR-0012 ACCEPTED — MediaEngine Unified Lifecycle (anti-leaky-abstraction):** after three real media engine implementations (VoiceEngine, SubtitleEngine, VideoEngine — Rule of Three + video multi-asset stress test), extract a single `MediaEngine` contract that standardizes the **lifecycle (process)** — resolve capability, select adapter, run, error handling, retry, telemetry, cost reporting, artifact publishing — while explicitly NOT standardizing payload/metadata (each engine keeps its own typed input/outcome).
