## Decisions Made

- **ModelGate v2 is a utility, not a service** — preserves Thin Orchestrator (ADR-0004).
- **Secret handling:** local MVP uses env vars (`OPENAI_API_KEY` etc., .env git-ignored); DB stores only `key_ref` (`env:<VAR>`). Production path: real vault.
- **`model_policy.yaml`** is the single source of truth for model + capability metadata; seeded idempotently.
- **Capability-gated selection** — `fyi provider models <capability>` shows only connected + capable models; `select`/`resolve` reject incompatible.
- **No provider connected → structured error** (`NO_MODEL_FOR_CAPABILITY`, non-retryable).
