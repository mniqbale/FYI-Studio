# Session Handoff - 2026-08-04 (Milestone 3: Cognitive Core — wiring built)

## Session Summary

**Objective:** Build the Milestone 3 (Cognitive Core) wiring: real AI workers using ModelGate v2, without yet requiring an API key to make the plumbing testable.

## What Was Built

### New @fyi/ai package
- `packages/ai/` — AI client with provider adapters via native fetch (no SDK):
  - OpenAI / OpenRouter / Groq / Together / Ollama → OpenAI-compatible `/chat/completions`
  - Anthropic → `/messages` (system as top-level field)
  - Gemini → `:generateContent`
- Structured errors: `RATE_LIMIT_EXCEEDED` (retryable), `PROVIDER_UNAVAILABLE`, `PROVIDER_ERROR`, `UNKNOWN_PROVIDER`
- 6 unit tests (fetch mocked, no real network)

### Real workers
- `workers/research-real/` — `research:real`, resolves via ModelGate, calls AiClient
- `workers/script-real/` — `text-synthesis:script:real`, resolves via ModelGate, calls AiClient
- Both follow the stateless BullMQ pattern, publish to `completion-queue`, structured JSON logging with job_id+execution_id

### Supervisor + policy
- `services/supervisor/src/config.ts` — added `research:real` → `research-real-queue`, `text-synthesis:script:real` → `script-real-queue`
- `packages/platform/model_policy.yaml` — added `research:real` + `text-synthesis:script:real` defaults

## Status: COMPLETE 🎉

Milestone 3 (Cognitive Core) is **complete**. The real AI pipeline works end-to-end via **Ollama Cloud**:

- `OLLAMA_BASE_URL=https://ollama.com/v1` (Ollama Cloud OpenAI-compatible endpoint)
- Model: `deepseek-v4-flash` (set as default in model_policy.yaml)
- A real job produced a **research brief with 5 real sources** + a **script with 8 scenes**, and reached **COMPLETED**.

### How the pipeline runs
1. Supervisor polls the ledger for PENDING jobs.
2. Dispatches `research:real` → real-research worker → ModelGate resolves `ollama/deepseek-v4-flash` → AiClient calls Ollama Cloud → research_brief stored in artifacts.
3. StepRunner advances → dispatches `text-synthesis:script:real` → real-script worker → generates script from the research_brief.
4. Job marked COMPLETED with merged artifacts + telemetry.
